# Legacy 2025 paths

This directory only exists to keep old external links working, notably those from the [official GSoC archive](https://summerofcode.withgoogle.com/archive/2025/projects).
Each `projects/<name>/README.md` here is a symlink to the project's page in [`permapage/`](../permapage/).

The 2025 program itself lives in [`program/2025/`](../program/2025/README.md).

Do not delete or extend this directory.
